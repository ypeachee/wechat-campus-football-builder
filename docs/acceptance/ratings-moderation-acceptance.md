# 球员评分与内容审核验收清单

## 评分规则

- [ ] 已完赛比赛显示球员评分区
- [ ] 未结束比赛提示“比赛结束后开放评分”
- [ ] 只有有出场记录的球员可评分
- [ ] 用户可选择 1–5 整星
- [ ] 1–5 星分别换算为 2/4/6/8/10 分
- [ ] 平均分按 10 分制显示一位小数
- [ ] 每个用户每场每球员只有一条评分
- [ ] 24 小时内允许修改一次
- [ ] 第二次修改被拒绝

## 主裁评分

- [ ] 已完赛且填写主裁的比赛显示“当值主裁评分”
- [ ] 未填写主裁时显示“主裁待定”且不能评分
- [ ] 主裁评分只允许 1–5 星
- [ ] 主裁评分按 2–10 分展示
- [ ] 每个用户每场主裁只能评分一次
- [ ] 24 小时内允许修改一次
- [ ] 主裁评分不显示评价输入框
- [ ] 主裁评分不触发敏感词或微信内容安全审核
- [ ] 主裁姓名修改后按新主裁重新评分

## 内容审核

- [ ] 空短评直接计入评分
- [ ] 本地 BLOCK 词命中时评价被拒绝
- [ ] 本地 REVIEW 词命中时评价进入待审核
- [ ] 微信内容安全返回 review 时进入待审核
- [ ] 微信内容安全返回 risky 时被拒绝
- [ ] 微信接口异常时评价不会直接公开
- [ ] 短评超过 100 字被拒绝
- [ ] 待审核、拒绝、隐藏评价不进入公开均分和评论

## 管理员

- [ ] 非管理员无法进入评分审核页
- [ ] 管理员可按待审核、被举报、已隐藏筛选
- [ ] 管理员可通过评价
- [ ] 管理员可拒绝评价
- [ ] 管理员可隐藏和恢复评价
- [ ] 处理举报后举报状态变为已处理
- [ ] 审核操作写入审计日志
- [ ] 管理员可新增、启停、删除敏感词
- [ ] 管理员可批量导入敏感词
- [ ] 单次导入超过 5000 条被拒绝

## 用户与隐私

- [ ] 未登录用户只能查看，不能评分或举报
- [ ] 同一用户不能重复举报同一评价
- [ ] 用户不能举报自己的评价
- [ ] 公开接口不返回 OpenID
- [ ] 公开评论只显示昵称
- [ ] 举报入口在评价列表中可见

## 合规

- [ ] 小程序简介已说明提供经审核的赛后评价
- [ ] 已删除“不提供用户发布内容服务”的旧表述
- [ ] 隐私保护指引已说明评价和审核数据用途
- [ ] 已提供举报和内容下线能力
- [ ] 生产环境已配置微信内容安全接口
- [ ] 管理员已了解审核和处置流程

## 回归

- [ ] 后端全量测试通过
- [ ] 小程序全量测试通过
- [ ] 主包不超过 1.5 MB
- [ ] 图片和音频资源不超过 200 KB
- [ ] iOS 和 Android 真机分别验证评分弹层、键盘和举报流程
